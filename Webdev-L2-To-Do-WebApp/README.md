# 📚 Study Planner

A simple and responsive **Study Planner** web application that helps students organize their study tasks. Users can add, edit, complete, and delete tasks while keeping pending and completed tasks organized separately.

## ✨ Features

* Add new study tasks
* View pending tasks
* Mark tasks as completed
* Move completed tasks to the Completed Tasks section
* Edit tasks inline
* Delete tasks
* Display pending and completed task counts
* Show task timestamps
* Save tasks using localStorage
* Friendly empty-state messages
* Responsive design for different screen sizes

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JavaScript)
* LocalStorage

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
4. Start adding your study tasks.

## 🎯 How It Works

1. Enter a study task in the input field.
2. Click **Add Task**.
3. The task appears under **Pending Tasks**.
4. Use **Edit** to modify the task.
5. Use **Complete** to move the task to **Completed Tasks**.
6. Use **Delete** to remove a task.
7. Tasks are stored in `localStorage`, so they remain after refreshing the page.
