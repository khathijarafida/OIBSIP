# Calculator

A simple and responsive calculator built using HTML5, CSS3, and Vanilla JavaScript.

## Features

- Basic arithmetic operations
- Addition, subtraction, multiplication, and division
- Modulus operation
- Decimal numbers
- Sequential calculations
- Backspace button
- Clear button
- Error handling for invalid operations
- Displays `Error` for consecutive operators such as `++`

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
